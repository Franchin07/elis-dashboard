# elis-dashboard
Dashboard per Ingegneria Digitale

## Link presenti
- stud.elis.org
- my.elis.org
- spaces.elis.org
- polimi.it/servizi-online
- webeep.polimi.it
- pasti.eliscollege.org
- sport.eliscollege.org
- biblioteca.elis.org

## Funzione Iframe
Con la funzione Iframe disattivata tutti i link verranno aperti in una pagina nuova, con Iframe attivato i link supportati verranno aperti direttamente nella dashboard con un pulsante per tornare indietro.

## Modalità Residente
Con la modalità Residente attivata verranno mostrati altri pulsanti, utili per chi sta in residenza maschile.

## Calendario lezioni
E' possibile aprire il calendario delle lezioni direttamente sulla nella dashboard; alternativamente si può scaricare un comodo file .ics per inserire il calendario direttamente sul proprio dispositivo.
